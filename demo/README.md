# Demo 使用说明

## 打开哪个文件

打开 `装修需求发现助手_Demo_V0.1.html`，双击即可，不需要起服务器，也不需要联网。

页面是纯前端演示版：数据全部模拟，不会上传任何内容；填写进度保存在浏览器本地，点右上角「重置」可以清空。第一次打开建议先点「填入示例需求」，会灌入一个 89㎡ 三口之家 + 养猫的场景，右侧发现助手会立刻推出建议。

## 为什么不要打开 `_demo_template.html`

模板文件（现在放在 `tools/_demo_template.html`）里字段数据是空的，它只是构建中间产物，直接打开只会看到空白表单区，且会和 Demo 共用浏览器同一份本地存储，出现"左侧空白但右侧有发现"的错乱现象。

## 怎么重新生成

字段规格来自 `outputs/01a0c95f-3b4f-7762-ad52-61bb13941fcc/装修需求采集表_字段清单_V1.xlsx`，构建脚本把字段数据注入模板生成 Demo：

```
python tools/build_demo.py
```

改了字段清单或模板后重新执行即可，Demo 与字段规格不会漂移。

## 怎么验证

```
node tests/demo.smoke.mjs
```

用无头 Chromium 跑「填写 → 发现 → 采纳 → 改一改 → 撤销 → 静默 → 摘要 → 提交前检查 → 重置」全流程，并回归验证直接打开模板文件时不会出现空白页与 NaN 完整度。
