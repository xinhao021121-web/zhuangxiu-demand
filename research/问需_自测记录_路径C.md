## 一、怎么算「卡住」

四类判据，逐条可核对——避免这份记录退化成个人感受：

| 类型 | 判据 | 例子 |
| --- | --- | --- |
| 读不懂（术语） | 标签或选项是行业说法，房主不知道它指什么、或不知道自己是哪一种 | 次净衣区、墙排水 |
| 答不上来（缺信息） | 答案不在房主手上，要量、要翻、要看图纸 | 层高 |
| 要清点（成本高） | 答得上，但要翻柜子数一遍，容易随手填一个数 | 鞋子数量、行李箱数量 |
| 要现场条件才能定 | 答案取决于量房时才知道的事 | （表单里已基本规避，见 2.4） |

## 二、结果

### 2.1 读不懂：最该改的一类（8 个字段）

这些字段的标签或选项是行话，而且**没有兜底选项**——房主只能硬猜一个，猜出来的值会被当成真实需求带进方案：

| 字段 | 大类 | 标签 | 选项 | 卡在哪 |
| --- | --- | --- | --- | --- |
| `br_secondhand` | 主卧 | 次净衣区 | 需要 / 不需要 | 「次净衣」是行业说法，房主不知道指穿了一次还没洗的衣服 |
| `sc_housekeeping` | 收纳与家政 | 家政柜 | 需要 / 不需要 | 「家政柜」是行业说法（放吸尘器、拖把的柜子） |
| `sc_valuable` | 收纳与家政 | 贵重物品存放 | 保险箱 / 密码抽 / 无 | 「密码抽」是行话 |
| `wc_basin` | 卫生间 | 一体台下盆 | 需要 / 不需要 | 「一体台下盆」要见过实物才懂 |
| `dev_drain` | 设备与系统 | 排水特殊需求 | 干区地漏 / 墙排水 / 露天阳台排水 | 三个选项全是行话，且没说「不清楚」 |
| `kt_dishwasher` | 厨房 | 洗碗机 | 前开式 / 水槽式 / 不需要 | 「前开式 / 水槽式」是型制术语 |
| `bl_hanger` | 阳台 | 晾晒方式 | 明装 / 暗装晾衣架 / 以烘干为主 | 「明装 / 暗装」是安装术语 |
| `kt_hood` | 厨房 | 油烟机形式 | 侧吸 / 顶吸 / 集成灶 | 房主常常不知道自家是哪种，也不知道该选哪种 |

**对照**：全表一共只有 9 个字段给了「不清楚 / 听设计师建议」这类兜底，而且**全部落在「认识你家」与「设备与系统」两个大类**（楼层位置、房屋现状、装修预算、风格偏好、空调、新风、水质、热水、取暖）。上面这 8 个字段横跨厨房 / 主卧 / 卫生间 / 阳台 / 收纳与家政，一个兜底都没有。

这是本次自测最具体的一条发现：**兜底选项的覆盖范围是按「字段设计的类别」给的，不是按「房主懂不懂」给的**。

### 2.2 答不上来：只有 1 个字段

| 字段 | 大类 | 标签 | 说明 |
| --- | --- | --- | --- |
| `base_height` | 认识你家 | 层高 | 房主手上没有这个数，要量一次才有。种子场景 d1 填了「2.75」——**这是理想化填写**，真实房主的完成度会低于种子数据 |

顺带一个连带结论：9 项「推荐填写」里没有一项需要现场测量（面积、现状、人口、老人、宠物、预算、入住时间、下厨频率、泡澡需求），所以「推荐项完成率 ≥ 80%」这个目标值本身不受「答不上来」影响——它受影响的是房主的意愿与耐心，那是访谈要问的。

### 2.3 要清点：5 个数字字段，风险不是卡点而是假数据

`ex_shoe_count`（鞋子数量）、`ex_boots`（高筒靴）、`sc_luggage`（行李箱）、`st_books`（藏书量）、`st_device_count`（需配置电器数）——答得上，但要翻柜子数一遍。**这里的问题不是房主答不出，而是他会随手填一个数**，而下游（收纳设计、柜体尺寸）会把它当成真的。

建议留给访谈验证：问一句设计师「客户填的鞋子数量、行李箱数量，你会照用吗」。如果答案是「不会，我到现场自己看」，这几个字段就该从表单里挪走或改成区间。

### 2.4 要现场条件才能定：表单里几乎没有

承重墙与梁位、上下水点位、配电回路、地面完成面衔接、定制柜安装垂直度——这些都没有进表单，而是落在 16 项《量房确认清单》里。

**这是一条正向结论**：产品文档 4.1 那条「属于现场的问题不进表单」的分工，在字段层面是成立的，不是一句口号。

## 四、给采集端的具体建议

按「能不能现在就改」分两栏，避免把研究结论直接当成排期：

| # | 建议 | 落点 | 现在能改吗 |
| --- | --- | --- | --- |
| 1 | 给 2.1 那 8 个字段补兜底（「不清楚，听设计师建议」或「不确定，量房时再定」），或者把标签改成生活说法（次净衣区 → 穿过的衣服挂哪） | 字段清单 Excel → `field-spec` | 改文案可以先做；改选项会让「不清楚」率进报表，建议等访谈回来一起定 |
| 2 | 层高给定一个「不知道，量房时确认」的路径，而不是让房主猜 | 同上 | 同上 |
| 3 | 数量类字段（2.3）在访谈里问一句「你会照用吗」，再决定留不留 | 无（研究结论） | 访谈时问 |

第 1 条里「改标签」的建议**只对 2.1 的 8 个字段成立**，不要顺手把全表文案改一遍——表单的其余部分已经去过术语化了，这是这次走查的另一半结论。
